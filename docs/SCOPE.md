# Scope

## Pages included

| Route | Page | Purpose |
| --- | --- | --- |
| `/` | **Homepage** | Demand-led. Creates demand and routes buyers. |
| `/products` | **Platform overview** | Journey-led summary of the four products + services router. |
| `/products/core` · `/indicate` · `/connect` · `/ultra` | **Product detail pages** | One page per tier: pricing, role, full includes, intelligence focus, journey nav. |
| `/products/discover` | **Genii Discover** | Standalone insight product. |
| `/products/managed-services` | **Managed Services** | Human QA support & AI exception management (+ governance). |
| `/products/enable` | **Genii Enable** | Professional services roll-out. |
| `/products/compare` | **Compare** | Full feature matrix, intelligence layers, how it works, governance, proof, FAQ. |

Mirrors the per-product IA of the current live site (geniianalytics.com).

## Explicitly excluded (this phase)

- Solutions detail pages (Customer Experience, Client Retentions, Sales
  Performance, Collections, Performance Management) — nav links present, pages
  not built yet.
- Company / Resources / Blog content pages.
- A working platform demo, gated content or authenticated areas.
- Live lead-form back-end, CRM integration and email delivery.
- Real analytics wiring (placeholders only).
- Multi-language / localisation.
- CMS integration (content is file-based for now — see `STRUCTURE.md`).

## Launch milestones

1. **M1 — Foundation (done):** Next.js + Tailwind v4 + shadcn scaffold, brand
   theme, docs, structure.
2. **M2 — Core pages (this build):** Homepage + Product page built from briefs.
3. **M3 — Content sign-off:** Genii approves copy, stats, logos and video.
4. **M4 — Integrations:** Lead routing (email/CRM), analytics IDs, real logos.
5. **M5 — Launch:** Vercel production deploy, domain, QA and go-live.
